Turn on local detection history?

The protection works either way. Turning this on saves local activity counts and enables the feedback buttons.

  • URLs are checked on this device. Ordinary visited URLs are not saved as readable text.
  • A private one-way identifier is kept locally so repeated checks of the same URL are counted once. It is not included in exports.
  • The extension saves local totals for checked URLs, results, ignored repeats, errors, and checking time.
  • A readable URL is saved only when you press a feedback button. Login details, query values, and page fragments are removed.
  • Reported paths can still contain personal information, so review an exported file before sharing it.
  • You choose if and when to export the results. You can pause or erase the local history at any time.
